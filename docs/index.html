How it works

No dashboards. No guilt. Just a hard limit.

3

Pick your limit

Three by default. Change it to anything from 1 to 50 in settings.

+1

Try to open another

Ctrl+T, a link, a new window — if you're at the limit, the new tab never gets to exist.

✓

Stay in the flow

Finish, close a tab, then open the next. One thing at a time.

Small, sharp, honest

Built to do one job.

Quiet by design

No counters or badges nagging you from the toolbar. The popup shows your three slots when you look.

Block or redirect

Drop the new tab, or load its link in the tab you came from.

Per-window or global

Count across every window, or give each window its own budget.

Never touches your tabs

Existing tabs are never closed. Only new ones are stopped.

Zero tracking

No analytics, no accounts. Settings stay on your device. The only request is an optional update check.

Every browser

Chrome, Edge, Brave, Opera, Vivaldi and Firefox. One codebase.

Install

Grab the latest build from the releases page, or load it straight from source.

Chrome · Edge · Brave

  1. Clone the repo or download the ZIP
  2. Open chrome://extensions
  3. Enable Developer mode
  4. Load unpacked → pick the extension folder

Firefox

  1. Clone the repo or download the ZIP
  2. Open about:debugging#/runtime/this-firefox
  3. Load Temporary Add-on…
  4. Pick extension/manifest.json
