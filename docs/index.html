Questions

How do I limit tabs in Chrome?

Install ThreeTabs. It allows 3 open tabs by default and closes any new tab beyond that. Change the limit from 1 to 50 in the settings.

Does it close my existing tabs?

No. Tabs that are already open are never touched. Only new tabs and windows beyond your limit are blocked.

Is it really free? Does it track me?

Free and open source (MIT). No analytics, no ads, no accounts. The only network request is an optional daily version check on GitHub that you can turn off.

Which browsers work?

Chrome, Edge, Brave, Opera, Vivaldi and Firefox 121 or newer.

Can I change the limit?

Yes: any number from 1 to 50, counted across all windows or per window. Blocked links can be dropped or opened in your current tab.
